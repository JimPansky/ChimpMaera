# ChimpMaera Support

ChimpMaera is provided without warranty, service-level objective or
production-support commitment.

When the distribution's repository offers issues or discussions, use them for
non-sensitive usage and development questions. Include the exact version or
archive hash, operating mode, redacted reproduction and relevant typed error
codes. Vulnerabilities follow [SECURITY.md](SECURITY.md).

Never include credentials, personal data, private prompts, host inventories or
non-public run artifacts. A response or workaround does not expand the local
PoC claim boundary.
