regular files/directories inside the resolved verification root. Purpose:

files in the isolated candidate tree. Rollback marker: revert the stability
commit; do not weaken the public-tree builder's existing independent checks.

provider behavior. The already completed integrated install/demo smoke is not
repeated because it cannot exercise this verifier-only correction; the fast
verifier, unit, checksum and deterministic public-tree gates are the relevant
