still detecting broken commit/tree anchors. Risk: a host-dependent replay
regression is not re-observed. Fallback: replay in disposable clones only after
a relevant implementation/revert change. Review marker: any new implementation
commit or rollback sequence.

Decision `AD-RC-003`: classify the 32 formatting findings as a separate quality
phase instead of silently correcting frozen public bytes. Purpose: preserve
the evidence and one-smoke-after-freeze boundary until correction value and
validation cost are explicit. Risk: the candidate retains style debt. Fallback:
make a formatting-only commit, refresh affected checksums and run proportionate
checks if the next phase decides correction is valuable. Review marker: the
source-hygiene risk decision.
