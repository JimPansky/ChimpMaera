# ChimpMaera v0.2 Wave 2 — provider-neutral PolicyEvaluator PDCA

Date: 2026-07-31  
Scope: local deterministic PoC, additive feature-branch implementation  
Maturity verdict: **HIGH for the bounded contract and internal provider slice**

## PLAN

Wave 1 proves the approval/effect boundary, but `AdminAiPoc` still selects a
rule directly from a provider-shaped policy. Wave 2 inserts an effect-free,
provider-neutral decision seam without changing the action catalogue or gate
authority format.

The versioned input binds actor, neutral capability, operation, resource,
tenant, materiality, adapter ID/version, action/scope digests and replay key.
Trusted profile/policy identity and generation remain server-owned. An
evaluator returns only `AUTO_GRANT`, `OWNER_ESCALATION` or `DENY`, reason codes,
constraints and a canonical digest; it cannot issue authority or call an
effect provider. The default provider is the existing deterministic static
policy wrapped behind this contract.

Compatibility boundary: the existing `/api/demo/admin-ai/decide` request and
v2 decision remain byte-shape compatible. The new evaluator evidence is
validated internally and is bound into the existing decision digest only via
the already-bound policy digest/outcome/reason data; no Wave 1 lease migration
is attempted.

## Adversarial review and gates

| Failure | Control | Evidence |
|---|---|---|
| Evaluator fabricates input/context | exact input/context digest revalidation | tamper matrix denies |
| Evaluator returns authority/effect data | exact-key output schema | extra fields deny |
| Unknown/malformed/throwing provider | fail closed; no fallback grant | deny/error tests |
| Policy source/semantic mismatch | bind source digest and canonical semantic digest | mismatch startup test |
| Provider-specific policy coupling | capability/operation/resource/adapter fields only | contract test |
| Existing decisions drift | legacy parity vectors | exact outcomes/actions and W1 tests pass |

White tests: all three existing policy outcomes, deterministic digest, exact
trusted context, and a conforming injected evaluator. Black tests: extra keys,
wrong request/input/context/policy digest, unknown outcome/reason, thrown
evaluation and result mutation. No black case may issue authority.

## ACT / autonomous decision audit

  internal provider. Risk: future network providers need timeouts. Fallback:
  add an async v2 interface rather than weakening v1. Review marker: first
  non-local evaluator proposal.
- Assumption: the action catalogue remains the trusted adapter boundary.
  Risk: evaluator neutrality alone can be mistaken for arbitrary provider
  support. Fallback: explicit docs and closed adapter IDs. Rollback: remove the
  evaluator seam without changing Wave 1 authority.
- Claim limit: no live LLM, remote policy service, timeout/cancellation,
  production policy engine or arbitrary plugin execution is implemented.
